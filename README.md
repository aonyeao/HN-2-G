# 海鸟精工施工工艺与品控双端展示

- index.html：默认响应式入口
- desktop.html：电脑端兼容入口
- mobile.html：手机端兼容入口
- assets/：标准Logo及8张重新生成的工序主图

页面按真实施工顺序组织：开工交底与保护 → 拆改砌筑 → 水电 → 吊顶木作 → 防水 → 泥瓦 → 涂装 → 安装与竣工验收。

材料体系限定中国、德国、意大利、瑞士。页面展示中财、可耐福、普睿司曼、西卡，并明确所有品牌、型号、产地、适用范围最终以项目选配表、合同、包装和进场资料为准。

部署到GitHub Pages时，将本目录内容直接放入仓库根目录，确保index.html与assets同级。所有资源均为英文文件名，单文件远小于25MB。
